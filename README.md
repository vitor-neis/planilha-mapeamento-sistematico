# Dataset de Mapeamento Sistemático - Modelos de Melhoria de Processo de Software

Este repositório contém o dataset resultante do Mapeamento Sistemático de Literatura (MSL) conduzido como parte da dissertação de mestrado intitulada **"UM ARTEFATO PARA APOIO À DECISÃO NA ESCOLHA CONTEXTUALIZADA DE MODELOS DE MELHORIA DE SOFTWARE"**, desenvolvida no Programa de Pós-Graduação em Computação Aplicada (PPGCA) da **UTFPR**.

O mapeamento representa a etapa de fundamentação empírica da pesquisa, cujo objetivo foi identificar, organizar e analisar estudos sobre a adoção, desafios e benefícios de modelos de melhoria como CMMI, ISO/IEC 15504 (SPICE), ISO/IEC 330xx e MPS.BR. Os dados aqui consolidados serviram de base para a formulação da teoria do Trade-off Estratégico e para a posterior concepção de um artefato prático de apoio à decisão (o protótipo SPI-Advisor).

## 📊 Conteúdo do Dataset

O arquivo principal `planilha-mapeamento-sistematico.csv` contém uma listagem consolidada de **294 artigos** científicos, extraídos das seguintes bases de dados:

* **IEEE Xplore**
* **Portal de Periódicos CAPES**
* **Scopus**

### Estrutura dos Dados

A planilha está organizada com as seguintes colunas:

1.  **Base de dados:** A fonte original de onde o artigo foi retornado (IEEE, CAPES ou SCOPUS).
2.  **Número:** Identificador sequencial do artigo dentro da base original.
3.  **Autor(es) e Ano:** Nome dos autores responsáveis e o ano de publicação.
4.  **Título do Artigo:** O título completo da obra.

## 🛠 Como utilizar

Este dataset está no formato **CSV (UTF-8)** para garantir a máxima compatibilidade e transparência. Você pode importá-lo facilmente em ferramentas como:
* Microsoft Excel / Google Sheets
* R / Python (Pandas)
* Gerenciadores de referências (Mendeley, Zotero)
